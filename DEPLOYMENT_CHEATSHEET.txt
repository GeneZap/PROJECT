# 🚀 Deployment Cheat Sheet

## VERCEL FRONTEND DEPLOYMENT

### When you see "Import project" screen:

```
Project Name:          BV-BRC_Dataset
Framework:             Vite
Root Directory:        frontend/  ← IMPORTANT!
```

### Environment Variables:

```
Variable:  VITE_API_BASE_URL
Value:     https://bvbrc-genezap-api.onrender.com
```

### Then: Click "Deploy"

---

## RENDER BACKEND DEPLOYMENT

### When you see "Configure" screen:

```
Name:                bvbrc-genezap-api
Environment:         Python 3
Region:              US East
Branch:              main
Root Directory:      backend/
Build Command:       pip install -r requirements.txt
Start Command:       uvicorn main:app --host 0.0.0.0 --port 10000
```

### Environment Variables (Click Advanced):

```
GENEZAP_ENV                       = production
GENEZAP_CORS_ORIGINS              = https://bv-brc-dataset.vercel.app
GENEZAP_LOG_LEVEL                 = INFO
GENEZAP_MAX_UPLOAD_MB             = 100
GENEZAP_MAX_POOL_FILE_MB          = 100
GENEZAP_MAX_POOL_FILES_PER_REQUEST= 25
GENEZAP_MAX_BATCH_FILES           = 50
```

### Then: Click "Create Web Service"

---

## FINAL STEP: Connect URLs

1. After Backend deploys, copy URL: `https://bvbrc-genezap-api.onrender.com`
2. Go to Vercel → Settings → Environment Variables
3. Update `VITE_API_BASE_URL` to the Render URL
4. Click "Save" then "Redeploy"
